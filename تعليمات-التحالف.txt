تشغيل نظام التحالفات
====================

1) ارفع ملفات الموقع السبعة إلى GitHub مثل المرة السابقة.
2) افتح Firebase Console ثم Firestore Database ثم Rules.
3) افتح ملف firestore.rules الموجود مع المشروع.
4) انسخ محتواه كاملًا والصقه بدل القواعد الحالية.
5) اضغط Publish.
6) أنشئ حسابين مختلفين لاختبار إرسال وقبول طلب التحالف.

مهم: رفع ملف firestore.rules إلى GitHub وحده لا يفعّل القواعد؛ يجب ضغط Publish داخل Firebase.
